# 摩擦方向性沙堆元胞自动机（同步水填充版）

本文件记录目前讨论确定的沙堆元胞自动机规则。

---

## 1. 网格与状态

- 使用二维正方形网格，大小 `L x L`。
- 每个元胞 `(i, j)` 只存储一个非负整数高度：

  ```text
  h(i, j) ∈ {0, 1, 2, ...}
  ```

- 采用开放边界：网格外的高度固定视为 `0`，沙粒可以流出系统。
- 不需要红黑格，也不需要为每个元胞额外保存状态。

---

## 2. 参数

| 参数 | 值 | 含义 |
|---|---|---|
| `theta` | `2` | 临界高差。局部坡度超过它时发生崩塌 |
| `q` | 已取消 | 不再限制一次局部倒塌的尝试次数 |
| `alpha` | 当前版本不使用 | 方向选择改为最低邻居均衡 |
| `mu` | 当前版本不使用 | 当前倒塌规则暂不含摩擦项 |

---

## 3. 邻居与不稳定判据

每个元胞只考虑上下左右四个冯·诺依曼邻居。

对于元胞 `c`，其邻居集合记为 `N(c)`。

元胞 `c` 不稳定，当且仅当存在邻居 `n ∈ N(c)`，使得：

```text
h(c) - h(n) > theta
```

边界外高度视为 `0`，因此边界格高度大于 `theta` 时也会不稳定，沙粒会向系统外流失。

---

## 4. 落沙驱动层

落沙模式可插拔，当前支持：

1. **均匀随机落沙**：无偏随机选择一个格子。
2. **手动落沙**：由用户输入或预设坐标列表给出落沙位置。
3. **正态分布落沙**：
   - 中心 `(mu_x, mu_y)`；
   - 标准差 `(sigma_x, sigma_y)`；
   - 在网格内逐格计算正态密度权重并归一化，再按离散概率选择格子；
   - 计算时可截断到中心附近 `±4 sigma` 的矩形以加速。

统一接口：

```text
class DropMode:
    reset(seed, params)
    next_site() -> (i, j)   # 只返回坐标，不直接修改 h
```

后期可以继续注册新的落沙模式。

### 硬性约束

> 上一轮落沙造成的连续崩塌结束前，不能进行下一轮落沙。

用状态机保证：

```text
IDLE      系统稳定，允许落下一粒沙
RELAXING  上一粒沙触发的松弛尚未结束
```

只有 `IDLE` 状态才允许调用 `next_site()`。
落沙模式只返回坐标，不直接修改高度场，也不能绕过上述状态门。

---

## 5. 完全同步松弛

每一轮松弛中，所有不稳定格都基于**同一份旧快照**制定倒塌计划，最后统一应用。

```python
while True:
    U = 当前 h 上的所有不稳定格

    if U 为空:
        松弛结束

    delta = 全零数组

    for c in U:
        alloc = collapse_plan(c, h)   # 只读本轮开始时的旧快照 h

        for 每个方向 n:
            delta[c] -= alloc[n]

            if n 在网格内:
                delta[n] += alloc[n]
            else:
                沙粒流出系统，不写 delta

    # 所有格子的计划都基于同一份旧快照，最后统一提交
    h += delta
```

要点：

- 所有格子互相看不到对方在本轮产生的变化。
- 遍历 `U` 的顺序不影响结果。
- 一个格子在本轮内计划移动的全部沙粒都先写入 `delta`，最后统一应用。
- 移动数必须在制定计划时直接累计，不能用 delta 反推，否则会漏算「流入又流出」的沙粒。

---

## 6. 局部倒塌计划：无 q 的水填充规则

对旧快照上的每个不稳定格 `c`：

1. 取当前高度：

   ```text
   H = h(c)
   ```

2. 四个方向的高度记为 `levels`，越界方向高度为 `0` 且永远不会升高。

3. 重复以下过程，直到：

   ```text
   H - min(levels) <= theta
   ```

   即自己与最低邻居的高差不再超过临界值。

4. 每一轮尝试：

   - 找到所有并列最低的方向：

     ```text
     M = argmin levels
     g = |M|
     ```

   - 如果 `H >= g`：
     - 向 `M` 中每个方向各移动一粒沙；
     - 内部邻居高度 `+1`；
     - 越界方向沙粒流出系统，高度保持 `0`；
     - `H -= g`。

   - 如果 `H < g`：
     - 沙粒不够给所有并列最低方向各一粒；
     - 按旋转后的确定性方向顺序，把剩余 `H` 粒逐一发出；
     - `H = 0`，结束。

5. 把每个方向的累计移动量作为 `alloc` 返回。

### 快速计算：分组水填充

上述过程不需要逐粒模拟，可以用「分组水填充」一次算出：

- 当前最低组高度为 `L`，组大小为 `g`。
- 下一组高度为 `L_next`（若不存在则视为无穷）。
- 每执行一轮，`H` 减少 `g`，当前最低组每个成员升高 `1`。
- 在当前最低组内达到稳定所需的轮数：

  ```text
  t_stop = ceil((H - L - theta) / (g + 1))
  ```

- 若 `t_stop` 小于升到下一组所需轮数，则停止。
- 否则把当前最低组抬到下一组高度，合并后继续。

特殊情况：

- **全边界最低组**：边界高度永远是 `0`，之后只向系统外排出，直到 `H <= theta`。
- **混合边界与内部最低组**：内部最低者一轮后离开该组，因此每轮最多批量处理一次。

## 7. 雪崩大小

每次落沙后，记录松弛期间实际移动的沙粒总数：

```text
avalanche_size = 本次松弛中所有 alloc 的总和
```

包括流出系统的沙粒。

---

## 8. 完整更新流程

```text
循环:
    1. 若系统仍不稳定:
           继续松弛，禁止落沙

    2. 系统稳定后:
           (i, j) = drop_mode.next_site()
           h[i][j] += 1

    3. 进入完全同步松弛:
           while 存在不稳定格:
               根据旧快照计算所有不稳定格的 alloc
               累加为 delta
               统一应用 delta

    4. 记录本次雪崩大小
       返回第 1 步
```

---

## 9. 规则特点

1. **无 q 限制**：每个格子松弛到局部坡度不超过 `theta` 为止。
2. **完全同步**：所有不稳定格基于同一旧快照制定计划，最后统一提交。
3. **无红黑格**：同步更新本身消除了扫描顺序偏差。
4. **无逐粒随机方向选择**：方向由最低邻居均衡决定。
5. **落沙模式可扩展**：均匀、手动、正态分布等模式都通过统一接口接入。
6. **落沙与松弛严格分离**：上一轮松弛结束前不能进行下一轮落沙。
7. **确定性强**：给定初始高度和落沙序列，整个演化过程完全可复现。
8. **开放边界自然流出**：越界方向是永久高度 `0` 的汇，系统最终达到动态平衡。

---

## 10. 当前未使用的旧参数

- `q`：已被「松弛到局部坡度不超过 `theta`」的停止条件取代。
- `alpha`：当前方向选择直接使用最低邻居均衡，不再使用方向权重指数。
- `mu`：当前倒塌规则暂不含摩擦概率；如需加入，可作为后续可选项。
